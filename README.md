# Dashboard Agrícola La Higuera (HTML)

Este repositorio contiene un dashboard HTML autocontenido para visualizar gastos de la temporada 2025–2026, con filtros, tablas, gráficos y vista comparativa con temporada 24–25.

## Estructura del proyecto

- `dashboard_la_higuera_25-26_dropdown.html`: archivo único con HTML, CSS y JavaScript integrados. Incluye:
  - Filtros de predio, cultivo, nivel 1, faena, métrica, meses y orden.
  - Vistas de **Resumen**, **Gráficos**, **Comparativo 24-25 vs 25-26** y **Detalle**.
  - Datos embebidos y capacidad de cargar CSV externos.

## Uso

1. Abre `dashboard_la_higuera_25-26_dropdown.html` en un navegador moderno (Chrome, Edge o Firefox).
2. Ajusta los filtros en la parte superior para cambiar las vistas.
3. (Opcional) Usa los botones de carga de CSV para actualizar la fuente de datos.

## Notas

- El archivo es 100% estático: no requiere servidor ni dependencias externas.
- Para actualizar datos permanentes, reemplaza el CSV embebido o genera un HTML actualizado desde la propia interfaz si esa opción está habilitada.
